GÜL ŞEKERLEME ANDROID APK DERLEME PAKETİ

Bu proje mevcut Cloudflare panelini Android WebView içinde açan basit bir uygulamadır.
Panel adresi: https://gul-sekerleme-panel.didemboncuk.workers.dev/

ÖNEMLİ:
- Bu ZIP bir APK değildir; GitHub Actions ile APK derlemek için kaynak projedir.
- Uygulama internet ve panelin çalışmasını gerektirir. Çevrimdışı kayıt/senkronizasyon içermez.
- Derleme sonucu doğrulanmış değildir.

TABLETTEN DERLEME ÖZETİ:
1. ZIP'i çıkarın.
2. GitHub'da yeni bir boş repository oluşturun.
3. Çıkarılan klasörün İÇİNDEKİ dosya ve klasörleri repository köküne yükleyin. ZIP dosyasını tek başına yüklemeyin.
4. Yüklenen dosyaları main dalına kaydedin.
5. Repository > Actions > Build Gül Şekerleme APK > Run workflow seçin.
6. İşlem yeşil tikle tamamlanırsa ilgili çalışmayı açın; Artifacts bölümündeki Gul-Sekerleme-APK dosyasını indirin.
7. İndirilen artifact ZIP'ini çıkarıp app-debug.apk dosyasına dokunun. Android güvenlik ekranı çıkarsa yalnızca kaynağa güveniyorsanız yükleyin.
